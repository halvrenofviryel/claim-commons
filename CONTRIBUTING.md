# Contributing

Contributions should make a claim boundary more inspectable.

Useful early contributions include:

- A counterexample where the current capsule or adapter overstates a result.
- A safely shareable real export and the upstream revision that produced it.
- A field-level mapping report that records retained, transformed, omitted, and unavailable information.
- An independent implementation of the draft schema or outcome derivation.
- Accessibility and low-resource usability findings.

Please do not submit private evaluation data, credentials, proprietary logs, or personal information. Synthetic fixtures must be labeled synthetic. A passing test does not by itself justify a broader compatibility, safety, adoption, or interoperability claim.

Open an issue before adding a new adapter. State the exact source format and revision, the fields admitted, the fields omitted, and the narrow claim the adapter would support.
